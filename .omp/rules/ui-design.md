# UI design principles

- Avoid adding explanatory, descriptive, or instructional text to the UI unless necessary.
- Prefer intuitive layouts, recognizable icons, visual hierarchy, and established interaction patterns to guide user actions.
- Communicate functionality through the design of the interface itself.
- Do not add redundant subtitles, helper text, labels, or descriptions that repeat information already conveyed by the UI.
- If an interaction requires lengthy explanations, improve its design before adding explanatory text.
- Use concise tooltips for actions whose meaning is not immediately apparent.
- Preserve essential accessibility labels, error messages, and safety-critical instructions.
- When text is necessary, keep it concise, specific, and actionable.
